# 2026-09-05 配色「少色原则」收敛（用户指令：配色方案少色原则）

## 触发
用户：「配色方案少色原则」→ 诊断真实色彩规模后执行收敛：中性灰阶 + 单一强调色 + 极少量语义色，去除装饰性多色。

## 实查诊断（动手前）
- `frontend-react/src/styles/components.css`：79 处裸 hex 硬编码（绕过 token），最严重 `#8a7a5c`（棕）被复制 20+ 次且不跟随主题 → 切主题时仍棕色（功能性 bug）。
- `tailwind.config.js`：`success:#4CAF50 / error:#E53935` 与 tokens 的 `#10b981 / #ef4444` 不一致（同一语义两套色）。
- `themes.css/tokens.css`：冗余近似灰（`--text-muted`=`--text-tertiary`、`--bg-secondary`=`--bg-elevated`）、死 token `--border-accent`（10 处定义 0 处引用）、`--accent-glow` 硬编码 10×。
- 模态强制暖白套色（`#f7f3ee/#ece5dc/#1a1612/#9c8e80/#c4956a/#a87b4f`）不跟随主题/暗色。

## 改动清单（frontend-react）
1. `components.css`：26× `#8a7a5c`→`var(--accent)`；`#d8d8d8`→`var(--border-strong)`；`#b85c5c`→`var(--error)`；暖白套色→`var(--bg-*)/var(--text-*)/var(--border-*)`；强调辉光 `rgba(138,122,92,..)`→`color-mix(in srgb,var(--accent) ..)`；`<QR 区域保留 #fff 保证可扫>`。残留 hex 79→2（均为刻意）。
2. `tailwind.config.js`：`success/error/warning/info` 改指 `var(--success/-error/-warning/-info)`；`pulseGold` 辉光改 `color-mix(var(--accent))`。
3. `tokens.css`/`themes.css`：删死 token `--border-accent`；`--accent-strong`→`var(--accent-dark)`；`--accent-glow`→`color-mix(var(--accent) 30%)`；`--bg-elevated`→`var(--bg-secondary)`；`--text-tertiary`→`var(--text-muted)`。

## 验收结果（全绿）
- `npm run lint` + `lint:fix`（prettier 类排序随 tailwind 增列变动）→ 0 error/0 warning ✅
- `npm run build`：97 模块、CSS 88.76 kB ✅
- Playwright 运行时 (5173) 零 console error ✅
- **主题跟随验证（关键）**：原硬编码 `#8a7a5c` 的元素（step/checkbox/selected/进度条）现四主题全跟随：frost-blue `rgb(74,144,217)`、forest-green `rgb(90,158,122)`、sakura-pink `rgb(232,154,176)`、luxury-gold `rgb(200,164,92)` ✅
