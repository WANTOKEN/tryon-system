## 登录报错 "Not authenticated" 修复（前端真 bug）
- **现象**：admin 后台 `admin/admin123` 登录后报 `Not authenticated`。
- **根因**：`LoginPage.onFinish` 在 `setAuth` 写入 token 之前就调用了 `authApi.getCurrentUser()`（→ `/auth/me/`）。请求拦截器从 localStorage 读不到 token，导致 `/me/` 不带 `Authorization`；后端 `HTTPBearer()` 无 token 返回 **403 "Not authenticated"**。
- **修复**：`authStore` 新增 `setToken(token)`（仅写入 token、不置 isAuthenticated）；登录成功后、调 `getCurrentUser` 之前先 `setToken(response.access_token)`，使 `/me/` 带上 Bearer token。等价验证：`/me/` 无 token → 403，带 token → 200。dev server HMR 已生效。
- 注：Playwright 安装 Chromium 在 macOS 因耗时较长被跳过，`npx playwright install chromium` 可后续手动装；真实浏览器冒烟可补做。
