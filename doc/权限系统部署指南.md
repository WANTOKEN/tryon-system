```python
from apps.accounts.models import Merchant

super_admin = Merchant.objects.create_superuser(
    username='admin',
    phone='13800138000',
    password='admin123',
    store_name='系统管理'
)

# 创建商家管理员
merchant_admin = Merchant.objects.create_user(
    username='merchant1',
    phone='13800138001',
    password='merchant123',
    store_name='测试商家',
    is_staff=True,
    role='merchant_admin'
)

# 分配权限组
from django.contrib.auth.models import Group
merchant_group = Group.objects.get(name='商家管理员')
merchant_admin.groups.add(merchant_group)
merchant_admin.save()

print("测试账号创建完成!")
print("超管账号: admin / admin123")
print("商家账号: merchant1 / merchant123")
```

## 🔧 常见问题

### 1. 迁移失败

```bash
# 删除迁移文件重新迁移
rm apps/accounts/migrations/0002_add_role_field.py
python manage.py makemigrations accounts
python manage.py migrate accounts
```

### 2. 权限不生效

```bash
# 重新设置权限
python manage.py setup_permissions

# 重启服务器
```

### 3. 前端菜单不显示

检查：
- 用户是否正确登录
- localStorage 中是否有 token 和 user 信息
- 浏览器控制台是否有错误
