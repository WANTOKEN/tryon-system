# AI 虚拟试衣系统 - 功能介绍

> **版本**: v2.0  
> **更新日期**: 2026-04-21

---

## 1. 产品定位

AI 虚拟试衣系统是一款面向**线下服装门店**的 B2B2C 智能穿搭工具。商家（门店）登录后，顾客可在门店平板/手机上拍摄形象照片，选择门店衣橱中的服装，由 AI 引擎生成虚拟试穿效果图。

---

## 2. 核心用户角色

| 角色 | 说明 | 使用场景 |
|------|------|----------|
| **商家（Merchant）** | 门店管理员/店员 | 登录系统、管理衣橱、查看试穿统计 |
| **顾客（Customer）** | 到店顾客（匿名） | 拍摄形象、选择服装、查看试穿效果 |
| **管理员（Admin）** | 平台运营人员 | Django Admin 后台管理所有数据 |

---

## 3. 核心业务流程

```
商家登录 → 管理衣橱（上传服装） → 顾客到店
  → 顾客拍摄形象照片 → 选择服装（每类1件） → 点击试穿
  → AI 引擎生成效果图 → 查看/收藏/分享 → 试穿结束
```

## 5. 功能详情

### 5.1 商家认证

#### 登录方式
- **账号密码登录**: 用户名 + 密码
- **手机验证码登录**: 手机号 + 6位验证码

#### 认证流程
```
1. 用户输入账号/手机号
2. 后端验证通过，生成 JWT Token
3. 前端存储 Token（localStorage）
4. 后续请求携带 Authorization: Bearer {token}
```

#### Token 管理
- Access Token: 有效期 1 小时
- Refresh Token: 有效期 7 天
- 自动刷新机制: Access Token 过期前 5 分钟自动刷新

### 5.2 衣橱管理

#### 服装分类体系

| 大类 | 中文名 | 子类示例 |
|------|--------|----------|
| tops | 上装 | T恤、衬衫、针织衫、卫衣 |
| bottoms | 下装 | 牛仔裤、休闲裤、短裤、半身裙 |
| dresses | 连衣裙 | 迷你裙、中长裙、长裙 |
| outerwear | 外套 | 夹克、大衣、西装、开衫 |
| shoes | 鞋 | 运动鞋、高跟鞋、靴子 |
| accessories | 配饰 | 帽子、围巾、包袋、腰带 |

#### 功能点
- **上传服装**: 支持图片上传，自动提取主色调
- **删除服装**: 软删除，保留历史记录关联
- **分类筛选**: 按大类/子类筛选
- **排序管理**: 支持自定义排序权重

---

### 5.3 形象管理

#### 拍照/上传
- **摄像头拍照**: 调用设备摄像头实时拍照
- **本地上传**: 从相册选择图片上传
- **图片要求**: 
  - 格式: JPG/PNG/WebP
  - 大小: 最大 10MB
  - 分辨率: 建议 1080p 以上

#### 图片处理
- 自动压缩至 2MB 以内
- 自动生成缩略图（300x300）
- 上传至 OSS，返回 CDN 加速 URL

### 5.4 AI 试穿

#### 支持的 AI 引擎

| 引擎 | 说明 | 特点 |
|------|------|------|
| aliyun | 阿里云 AI 试穿 | 稳定、速度快 |
| tencent | 腾讯云 AI 试穿 | 效果细腻 |
| seeddance | SeedDance | 开源方案 |

#### 试穿流程
```
1. 用户选择形象照片
2. 选择服装（每类最多1件）
3. 点击"开始试穿"
4. 后端创建任务，返回 task_id
5. 前端轮询任务状态（每2秒）
6. 任务完成，展示效果图
7. 扣减配额
```

#### 状态流转
```
pending → processing → completed
                    ↘ failed
```

---

### 5.5 试穿记录

#### 记录管理
- **列表展示**: 按时间倒序，支持分页
- **收藏功能**: 标记喜欢的效果
- **删除功能**: 软删除，保留数据
- **会话隔离**: 每个顾客会话独立

#### 会话管理
- 前端生成 session_id（UUID v4）
- 存储在 sessionStorage
- 刷新页面保持，关闭浏览器重置
- 同一会话的记录共享

---

### 5.6 多语言支持

#### 支持语言
- **zh-CN**: 简体中文（默认）
- **zh-TW**: 繁体中文
- **en**: English

#### 切换方式
- 设置弹窗选择语言
- 自动保存到 localStorage
- 刷新页面保持语言设置

---

### 5.7 配额管理

#### 配额规则
- 每个商家有固定试穿次数配额
- 每次成功试穿扣减 1 次
- 每月 1 日自动重置配额

#### 展示方式
- 进度条显示剩余配额
- 配额不足时提示
- 配额用尽时禁止试穿

---

### 5.8 数据加密

#### 加密方式
- **算法**: XOR + Base64
- **开关**: 可配置启用/禁用
- **范围**: 敏感字段（手机号等）

#### 用途
- 前端传输加密
- 后端存储加密
- 日志脱敏展示

## 6. 技术特性

### 6.1 性能优化

- **Redis 缓存**: 配额、分类统计缓存
- **批量操作**: bulk_create 减少数据库往返
- **原子操作**: F() 表达式保证并发安全
- **事务保护**: transaction.atomic() 保证数据一致性

### 6.2 安全特性

- **JWT 认证**: 无状态、可扩展
- **CORS 配置**: 严格限制允许域名
- **SQL 注入防护**: ORM 参数化查询
- **XSS 防护**: 前端输入转义

### 6.3 可观测性

- **结构化日志**: JSON 格式，便于分析
- **彩色日志**: 终端输出带颜色区分
- **请求追踪**: 每个请求唯一 ID
