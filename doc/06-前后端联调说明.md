# 前后端联调说明

本文档说明前后端数据交互的关键流程，特别是图片 URL 的处理。

---

## 图片存储与 URL 生成流程

### 1. 上传流程

```
前端上传图片 → 后端接收 → 存储到 OSS/本地 → 返回预签名 URL
```

**后端处理** (`apps/common/services/storage_service.py`):

```python
# StorageService 统一处理存储
storage = StorageService()
storage_key, stored_url, is_dup = storage.upload_file(
    file_obj=file,
    filename='avatar.png',
    folder='avatars',
    tenant_id=str(merchant.id),
)

# 如果是 OSS，生成预签名 URL
if storage.is_oss:
    presigned_url = storage.get_signed_url(storage_key, expires=86400)
```

### 2. 试穿结果存储流程

```
AI 引擎返回结果 URL → 后端下载 → 存储到 OSS → 生成预签名 URL → 返回前端
```

**SeedDream 引擎处理** (`apps/tryon/ai_engines/seeddance.py`):

```python
def _download_and_store_result(self, result_url, ...):
    # 1. 下载 AI 生成的结果图片
    response = requests.get(result_url, timeout=60)
    
    # 2. 存储到 OSS
    storage = StorageService()
    storage_key, stored_url, is_dup = storage.upload_file(...)
    
    # 3. 生成预签名 URL（24小时有效）
    if storage.is_oss and storage_key:
        presigned_url = storage.get_signed_url(storage_key, expires=86400)
        return presigned_url
    
    return stored_url  # 本地存储直接返回
```

## URL 类型说明

### OSS 预签名 URL

**格式**:
```
https://bucket-name.oss-cn-shanghai.aliyuncs.com/path/file.png?OSSAccessKeyId=xxx&Signature=xxx&Expires=xxx
```

**特点**:
- 包含签名参数 `OSSAccessKeyId`、`Signature`、`Expires`
- 有时效性（默认 24 小时）
- 无需额外鉴权即可访问

### 本地存储 URL

**格式**:
```
http://localhost:8888/media/avatars/abc123.png
```

**特点**:
- 通过后端 Nginx/Django 提供静态文件服务
- 无时效限制

## 前端处理指南

### 1. 图片显示

前端收到 `result_url` 后直接使用，无需额外处理：

```javascript
// 试穿结果
<img src={record.result_url} alt="试穿结果" />

// 衣橱服装
<img src={clothing.image_url} alt={clothing.name} />
```

### 2. 试穿请求 - 完整上传

```javascript
const formData = new FormData();
formData.append('avatar', avatarFile);  // 头像图片文件
formData.append('clothing_uuids', 'uuid1,uuid2');  // 衣橱服装 UUID
formData.append('session_id', 'session_xxx');
formData.append('ai_engine', 'aliyun');

fetch('/api/v1/tryon/generate/', {
  method: 'POST',
  body: formData
});
```

### 3. 试穿请求 - Key 复用（推荐）

**场景一：复用历史头像**

用户从历史记录中选择之前用过的头像，无需重新上传：

```javascript
// 从历史记录获取 avatar_key
const historyRecord = historyRecords[0];
const avatarKey = historyRecord.avatar_key;  // 或 historyRecord.uuid

const formData = new FormData();
formData.append('avatar_key', avatarKey);  // 传 key 而非文件
formData.append('clothing_uuids', 'uuid1,uuid2');
formData.append('session_id', 'session_xxx');

fetch('/api/v1/tryon/generate/', {
  method: 'POST',
  body: formData
});
```

**场景二：复用衣橱服装**

衣橱列表返回 `image_key`，前端可直接使用：

```javascript
// 衣橱服装数据结构
{
  "uuid": "cloth_xxx",
  "name": "白色T恤",
  "image_url": "https://oss.xxx/wardrobe/xxx.jpg?signature=...",  // 预签名 URL
  "image_key": "wardrobe/xxx.jpg",  // OSS key，用于复用
  "category": "tops"
}

// 提交试穿时使用 uuid
const formData = new FormData();
formData.append('avatar', avatarFile);
formData.append('clothing_uuids', 'cloth_xxx,cloth_yyy');  // 用 uuid 复用
formData.append('session_id', 'session_xxx');
```

### 4. 接口参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `avatar` | File | 二选一 | 头像图片文件（JPG/PNG，最大 10MB） |
| `avatar_key` | String | 二选一 | 已上传头像的 key，支持两种格式：<br>1. OSS key: `tryon_avatars/xxx.jpg`<br>2. 历史记录 uuid: `tryon_xxx` |
| `clothing_uuids` | String | 否 | 衣橱服装 UUID，多个用逗号分隔 |
| `custom_clothes` | JSON | 否 | 自定义服装，JSON 数组格式 |
| `session_id` | String | 是 | 会话 ID |
| `ai_engine` | String | 否 | AI 引擎，默认 `aliyun` |

### 5. 响应数据结构

```javascript
// 试穿记录
{
  "uuid": "tryon_xxx",
  "avatar_url": "https://oss.xxx/tryon_avatars/xxx.jpg?signature=...",
  "avatar_key": "tryon_avatars/xxx.jpg",  // 可用于下次复用
  "result_url": "https://oss.xxx/tryon_results/xxx.jpg?signature=...",
  "result_key": "tryon_results/xxx.jpg",  // 可用于下次复用
  "status": "completed",
  "clothing": [...]
}
```

## 后端 URL 处理函数

### `get_full_url(url, use_presigned=True)`

位置: `apps/common/utils/url_utils.py`

功能:
- 如果是相对路径，拼接完整 URL
- 如果是 OSS URL 且 `use_presigned=True`，生成预签名 URL
- 如果已经是预签名 URL，直接返回

```python
from apps.common.utils.url_utils import get_full_url

# 示例
url = get_full_url(record.result_url)  # 自动处理 OSS 预签名
```

### `StorageService.get_signed_url(key, expires=3600)`

位置: `apps/common/services/storage_service.py`

功能:
- OSS 存储：生成预签名 URL
- 本地存储：返回完整 URL

```python
from apps.common.services.storage_service import StorageService

storage = StorageService()
presigned_url = storage.get_signed_url('tryon_results/abc123.png', expires=86400)
```

## 环境配置

### 开发环境（本地存储）

```env
STORAGE_TYPE=local
```

图片存储在 `media/` 目录，通过 Django 提供静态文件服务。

### 生产环境（OSS 存储）

```env
STORAGE_TYPE=oss
OSS_ACCESS_KEY_ID=your-access-key-id
OSS_ACCESS_KEY_SECRET=your-access-key-secret
OSS_BUCKET_NAME=your-bucket-name
OSS_ENDPOINT=oss-cn-shanghai.aliyuncs.com
OSS_DOMAIN=cdn.yourdomain.com  # 可选，自定义域名
```

图片存储在阿里云 OSS，返回预签名 URL。

## Key 复用机制（通用）

### 核心原理

**存储 key** 是图片在存储系统中的唯一标识，与存储类型无关：

| 存储类型 | URL 示例 | Key 示例 |
|----------|----------|----------|
| OSS | `https://bucket.oss.xxx/wardrobe/abc.jpg?sign=...` | `wardrobe/abc.jpg` |
| 本地 | `http://localhost:8888/media/wardrobe/abc.jpg` | `wardrobe/abc.jpg` |

**前端只需传递 key，后端自动处理**：
- OSS: 生成预签名 URL
- 本地: 拼接完整 URL

### 工具函数

```python
# apps/common/utils/url_utils.py

# 从 URL 提取 key
key = get_key_from_url(url)
# OSS: https://bucket.oss.xxx/wardrobe/abc.jpg → wardrobe/abc.jpg
# 本地: /media/wardrobe/abc.jpg → wardrobe/abc.jpg

# 从 key 获取 URL（自动处理 OSS 预签名）
url = get_url_by_key(key)
# OSS: 返回预签名 URL
# 本地: 返回完整 URL
```

### 前端使用

**1. 衣橱服装返回 image_key**

```javascript
// GET /api/v1/wardrobe/clothing/
{
  "uuid": "cloth_xxx",
  "name": "白色T恤",
  "image_url": "https://oss.xxx/wardrobe/abc.jpg?sign=...",  // 预签名 URL
  "image_key": "wardrobe/abc.jpg"  // 存储 key（通用）
}
```

**2. 试穿记录返回 avatar_key 和 result_key**

```javascript
// GET /api/v1/tryon/records/
{
  "uuid": "tryon_xxx",
  "avatar_url": "https://oss.xxx/tryon_avatars/abc.jpg?sign=...",
  "avatar_key": "tryon_avatars/abc.jpg",  // 可复用
  "result_url": "https://oss.xxx/tryon_results/abc.jpg?sign=...",
  "result_key": "tryon_results/abc.jpg"  // 可复用
}
```

**3. 复用 key 提交试穿**

```javascript
// 方式一：复用历史头像的 key
formData.append('avatar_key', 'tryon_avatars/abc.jpg');

// 方式二：复用衣橱服装的 key（通过 uuid）
formData.append('clothing_uuids', 'cloth_xxx,cloth_yyy');

// 方式三：复用历史记录 uuid
formData.append('avatar_key', 'tryon_xxx');  // 历史记录 uuid
```

### 优势

| 特性 | 说明 |
|------|------|
| **存储无关** | 同一套代码支持 OSS 和本地存储 |
| **减少带宽** | 不重复上传相同图片 |
| **提升体验** | 响应更快，用户无需等待上传 |
| **节省存储** | 避免重复存储相同文件 |

## 常见问题

### Q1: 前端显示图片 403 Forbidden

**原因**: OSS Bucket 是私有的，需要预签名 URL 才能访问。

**解决**: 确保后端返回的是预签名 URL，检查 `STORAGE_TYPE=oss` 配置。

### Q2: 图片 URL 过期无法显示

**原因**: 预签名 URL 有时效性（默认 24 小时）。

**解决**: 
- 前端监听图片加载失败，触发刷新
- 或在查看历史记录时重新请求 API

### Q3: 本地开发图片无法显示

**原因**: 本地存储的图片需要 Django 提供静态文件服务。

**解决**: 
- 确保 `python manage.py runserver` 正在运行
- 检查 `MEDIA_URL` 和 `MEDIA_ROOT` 配置
