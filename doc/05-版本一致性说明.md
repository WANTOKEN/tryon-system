## 版本锁定策略

### Python 依赖

使用 `==` 精确版本锁定，确保所有环境安装相同版本：

```text
Django==5.2.13  # ✅ 精确版本
# Django>=5.0   # ❌ 不推荐：可能导致版本不一致
```

### Node.js 依赖

使用 `^` 语义化版本，允许小版本更新：

```json
{
  "react": "^18.2.0"  // 允许 18.2.x，不允许 18.3.0 或 19.0.0
}
```

**生产构建时锁定版本**：

```bash
# 生成 package-lock.json
npm install

# 使用锁定文件安装
npm ci
```

## 版本验证命令

### 开发环境验证

```bash
# Python 版本
python --version
# 期望输出: Python 3.11.x

# Django 版本
python -c "import django; print(django.VERSION)"
# 期望输出: (5, 2, 13, 'final', 0)

# MySQL 版本
docker exec tryon-mysql mysql --version
# 期望输出: mysql  Ver 8.0.x

# Redis 版本
docker exec tryon-redis redis-server --version
# 期望输出: Redis server v=7.x.x

# Node.js 版本
node --version
# 期望输出: v20.x.x

# React 版本
cd frontend-react
npm list react
# 期望输出: react@18.2.x
```

### 生产环境验证

```bash
# 进入后端容器
docker exec -it tryon-backend python --version
docker exec -it tryon-backend python -c "import django; print(django.VERSION)"

# 进入前端容器（如有）
docker exec -it tryon-frontend cat /app/version.txt
```

## 版本升级流程

### 升级前检查

1. **查看变更日志**：检查新版本的 breaking changes
2. **测试环境验证**：先在开发环境测试升级
3. **依赖兼容性**：确保相关依赖兼容

### 升级步骤

```bash
# 1. 更新 requirements.txt 中的版本号
# 2. 重新安装依赖
pip install -r requirements.txt

# 3. 运行测试
python manage.py test

# 4. 更新 Dockerfile 中的基础镜像（如需要）
# 5. 重新构建 Docker 镜像
docker build -t tryon-backend:latest .

# 6. 部署到生产环境
docker-compose -f docker/docker-compose.prod.yml up -d
```

## 常见版本问题

### Q1: 本地 Python 版本不是 3.11

**问题**: 本地安装了 Python 3.10 或 3.12

**解决**: 使用 pyenv 或虚拟环境管理多版本

```bash
# 使用 pyenv (macOS/Linux)
brew install pyenv
pyenv install 3.11.9
pyenv local 3.11.9

# Windows: 直接安装 Python 3.11
winget install Python.Python.3.11
```

### Q2: MySQL 版本不匹配

**问题**: 本地 MySQL 是 5.7，生产是 8.0

**解决**: 使用 Docker 确保版本一致

```bash
# 停止本地 MySQL 服务
# 使用 Docker 运行 MySQL 8.0
docker run -d --name tryon-mysql \
  -e MYSQL_ROOT_PASSWORD=Root@AiTryon2026 \
  -p 3308:3306 \
  mysql:8.0
```

### Q3: Node.js 版本不匹配

**问题**: 本地 Node.js 版本过低或过高

**解决**: 使用 nvm 管理多版本

```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# 安装并使用 Node.js 20
nvm install 20
nvm use 20
nvm alias default 20
```

### Q4: 依赖版本冲突

**问题**: `pip install` 报错版本冲突

**解决**: 使用虚拟环境隔离

```bash
# 创建新的虚拟环境
python -m venv .venv --clear
source .venv/bin/activate  # macOS
.\.venv\Scripts\Activate.ps1  # Windows

# 重新安装
pip install -r requirements.txt
```
