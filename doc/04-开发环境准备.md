## 系统要求

> ⚠️ **重要**: 开发环境版本必须与生产环境保持一致，详见 [版本一致性说明](./05-版本一致性说明.md)

| 软件 | 精确版本 | 说明 |
|------|----------|------|
| Python | **3.11.x** | 与 Dockerfile `python:3.11-slim` 一致 |
| Node.js | **20.x** | 与 `frontend-react/Dockerfile` 一致 |
| MySQL | **8.0** | 与 `docker-compose.yml` 一致 |
| Redis | **7.x** | 与 `docker-compose.yml` 一致 |
| Git | 最新版 | 版本控制 |

### 硬件建议

- **内存**: 8GB 以上（推荐 16GB）
- **硬盘**: 20GB 可用空间
- **CPU**: 4 核心以上

## Windows 环境安装

### 1. 安装 Git

1. 访问 [Git 官网](https://git-scm.com/download/win) 下载安装包
2. 运行安装程序，保持默认选项即可
3. 安装完成后，打开 **PowerShell** 或 **命令提示符**，验证安装：

```powershell
git --version
# 输出示例: git version 2.44.0.windows.1
```

### 2. 安装 Python

#### 方法一：官网安装（推荐）

1. 访问 [Python 官网](https://www.python.org/downloads/) 下载 Python 3.11.x
2. 运行安装程序，**务必勾选**：
   - ✅ **Add Python to PATH**
   - ✅ **Install pip**
3. 点击 **Install Now** 完成安装

#### 方法二：使用 winget（Windows 11 自带）

```powershell
winget install Python.Python.3.11
```

#### 验证安装

```powershell
python --version
# 输出: Python 3.11.x

pip --version
# 输出: pip 24.x from ...
```

### 3. 安装 Node.js

#### 方法一：官网安装（推荐）

1. 访问 [Node.js 官网](https://nodejs.org/) 下载 **20.x LTS** 版本
2. 运行安装程序，保持默认选项
3. 安装完成后验证：

```powershell
node --version
# 输出: v20.x.x

npm --version
# 输出: 10.x.x
```

#### 方法二：使用 winget

```powershell
winget install OpenJS.NodeJS.LTS
```

### 4. 安装 MySQL

#### 方法一：使用 Docker（推荐）

1. 安装 [Docker Desktop](https://www.docker.com/products/docker-desktop/)
2. 启动 Docker Desktop
3. 运行 MySQL 容器：

```powershell
docker run -d --name tryon-mysql `
  -e MYSQL_ROOT_PASSWORD=Root@AiTryon2026 `
  -e MYSQL_DATABASE=tryon_system `
  -p 3308:3306 `
  mysql:8.0 `
  --character-set-server=utf8mb4 `
  --collation-server=utf8mb4_unicode_ci
```

#### 方法二：本地安装

1. 访问 [MySQL 官网](https://dev.mysql.com/downloads/installer/) 下载安装包
2. 运行安装程序，选择 **Developer Default** 或 **Server only**
3. 设置 root 密码为 `Root@AiTryon2026`
4. 配置端口为 `3308`（避免与其他 MySQL 冲突）

### 5. 安装 Redis

#### 使用 Docker（推荐）

```powershell
docker run -d --name tryon-redis `
  -p 6379:6379 `
  redis:7-alpine `
  redis-server --appendonly yes
```

#### 使用 WSL2 + Redis

```powershell
# 在 WSL2 Ubuntu 中
sudo apt update
sudo apt install redis-server
sudo service redis-server start
```

### 6. 安装 Make（可选）

Windows 默认没有 `make` 命令，可以使用以下替代方案：

#### 方法一：使用 chocolatey 安装

```powershell
# 先安装 chocolatey（管理员 PowerShell）
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

# 安装 make
choco install make
```

#### 方法二：直接使用 Python 命令

```powershell
# 代替 make dev
python manage.py runserver 0.0.0.0:8888

# 代替 make migrate
python manage.py makemigrations
python manage.py migrate
```

## macOS 环境安装

### 1. 安装 Homebrew（包管理器）

打开 **终端**，执行：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

安装完成后，根据提示将 Homebrew 添加到 PATH（M1/M2/M3 芯片需要）：

```bash
# Apple Silicon (M1/M2/M3)
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

# Intel 芯片
echo 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/usr/local/bin/brew shellenv)"
```

### 2. 安装 Git

```bash
brew install git

# 验证
git --version
# 输出: git version 2.x.x
```

### 3. 安装 Python

```bash
# 安装 Python 3.11
brew install python@3.11

# 创建软链接（如果需要）
sudo ln -sf /opt/homebrew/bin/python3.11 /opt/homebrew/bin/python3
sudo ln -sf /opt/homebrew/bin/pip3.11 /opt/homebrew/bin/pip3

# 验证
python3 --version
# 输出: Python 3.11.x

pip3 --version
# 输出: pip 24.x from ...
```

### 4. 安装 Node.js

```bash
# 安装 Node.js 20.x LTS
brew install node@20

# 或者使用 nvm（推荐，可管理多版本）
brew install nvm
mkdir ~/.nvm
echo 'export NVM_DIR="$HOME/.nvm"' >> ~/.zshrc
echo '[ -s "/opt/homebrew/opt/nvm/nvm.sh" ] && \. "/opt/homebrew/opt/nvm/nvm.sh"' >> ~/.zshrc
source ~/.zshrc

# 使用 nvm 安装 Node.js
nvm install 20
nvm use 20
nvm alias default 20

# 验证
node --version
# 输出: v20.x.x

npm --version
# 输出: 10.x.x
```

### 5. 安装 MySQL

#### 方法一：使用 Docker（推荐）

```bash
# 安装 Docker Desktop
brew install --cask docker

# 启动 Docker Desktop（从应用程序文件夹）

# 运行 MySQL 容器
docker run -d --name tryon-mysql \
  -e MYSQL_ROOT_PASSWORD=Root@AiTryon2026 \
  -e MYSQL_DATABASE=tryon_system \
  -p 3308:3306 \
  mysql:8.0 \
  --character-set-server=utf8mb4 \
  --collation-server=utf8mb4_unicode_ci
```

#### 方法二：本地安装

```bash
# 安装 MySQL
brew install mysql@8.0

# 启动 MySQL 服务
brew services start mysql@8.0

# 初始化安全配置
$(brew --prefix mysql@8.0)/bin/mysql_secure_installation

# 创建数据库
mysql -u root -p
# 输入密码后执行：
CREATE DATABASE tryon_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 6. 安装 Redis

#### 方法一：使用 Docker（推荐）

```bash
docker run -d --name tryon-redis \
  -p 6379:6379 \
  redis:7-alpine \
  redis-server --appendonly yes
```

#### 方法二：本地安装

```bash
# 安装 Redis
brew install redis

# 启动 Redis 服务
brew services start redis

# 验证
redis-cli ping
# 输出: PONG
```

### 7. 安装 Make

macOS 自带 `make` 命令，无需额外安装。如果没有，可以通过 Xcode 命令行工具安装：

```bash
xcode-select --install
```

## 项目初始化

### 1. 克隆项目

```bash
# Windows PowerShell / macOS Terminal
git clone <项目仓库地址>
cd my_project
```

### 2. 创建 Python 虚拟环境

#### Windows

```powershell
# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
.\.venv\Scripts\Activate.ps1

# 如果遇到权限问题，先执行：
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

#### macOS

```bash
# 创建虚拟环境
python3 -m venv .venv

# 激活虚拟环境
source .venv/bin/activate
```

### 3. 安装 Python 依赖

```bash
# 确保已激活虚拟环境
pip install -r requirements.txt
```

### 4. 安装前端依赖

```bash
cd frontend-react2
npm install
cd ..
```

### 5. 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env
```

编辑 `.env` 文件，配置数据库连接：

```ini
# 数据库配置
DB_NAME=tryon_system
DB_USER=root
DB_PASSWORD=Root@AiTryon2026
DB_HOST=localhost
DB_PORT=3308

# Redis 配置
REDIS_URL=redis://localhost:6379/0
```

### 6. 初始化数据库

```bash
# 执行数据库迁移
python manage.py migrate

# 或使用 Makefile
make migrate
```

### 7. 创建超级用户（可选）

```bash
python manage.py createsuperuser
# 按提示输入用户名、密码
```

## 验证安装

### 1. 验证后端服务

```bash
# 启动后端服务
python manage.py runserver 0.0.0.0:8888

# 或使用 Makefile
make dev
```

访问 http://localhost:8888/api/v1/health/ 应返回：

```json
{"status": "ok", "version": "1.0.0"}
```

### 2. 验证前端服务

打开新的终端窗口：

```bash
cd frontend-react2
npm run dev
```

访问 http://localhost:5173 应显示前端页面。

### 3. 验证数据库连接

```bash
python manage.py dbshell
# 进入 MySQL 命令行，输入 \q 退出
```

### 4. 验证 Redis 连接

```bash
# Windows (Docker)
docker exec -it tryon-redis redis-cli ping
# 输出: PONG

# macOS
redis-cli ping
# 输出: PONG
```

## 常见问题

### Q1: Python 虚拟环境激活失败（Windows）

**问题**: 执行 `.\.venv\Scripts\Activate.ps1` 报错权限问题

**解决**:

```powershell
# 以管理员身份运行 PowerShell，执行：
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 然后重新激活
.\.venv\Scripts\Activate.ps1
```

### Q2: pip 安装依赖失败

**问题**: 部分包安装超时或失败

**解决**: 使用国内镜像源

```bash
# 临时使用
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 永久配置
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q3: npm 安装依赖失败

**问题**: npm install 报错网络问题

**解决**: 使用国内镜像源

```bash
# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 或使用 nrm 管理
npm install -g nrm
nrm use taobao
```

### Q4: MySQL 连接失败

**问题**: `Can't connect to MySQL server`

**解决**:

1. 确认 MySQL 服务已启动
2. 检查端口是否正确（默认 3308）
3. 检查密码是否正确

```bash
# Docker 方式检查
docker ps | grep mysql
docker logs tryon-mysql

# 本地方式检查
# Windows: 服务管理器中查看 MySQL 服务状态
# macOS: brew services list
```

### Q5: Redis 连接失败

**问题**: `Error 10061` 或连接被拒绝

**解决**:

```bash
# Docker 方式
docker ps | grep redis
docker restart tryon-redis

# 本地方式
# macOS
brew services restart redis
```

### Q6: 端口被占用

**问题**: `Address already in use`

**解决**:

```bash
# Windows - 查找占用端口的进程
netstat -ano | findstr :8888
taskkill /PID <进程ID> /F

# macOS - 查找并终止进程
lsof -i :8888
kill -9 <PID>
```

### Q7: M1/M2/M3 Mac 安装 mysqlclient 失败

**问题**: `ld: library not found for -lssl`

**解决**:

```bash
# 安装 openssl
brew install openssl

# 设置编译标志
export LDFLAGS="-L$(brew --prefix openssl)/lib"
export CPPFLAGS="-I$(brew --prefix openssl)/include"

# 重新安装
pip install mysqlclient
```

### Q8: 前端页面空白

**问题**: 访问前端显示空白页

**解决**:

1. 检查控制台是否有错误
2. 确认后端服务已启动
3. 检查 `.env` 中的 API 配置

```bash
# 检查前端环境变量
cat frontend-react2/.env
# 应包含:
# VITE_API_BASE_URL=/api/v1
# VITE_API_HOST=http://localhost:8888
```

## 快速启动脚本

### Windows (start-dev.ps1)

```powershell
# start-dev.ps1 - Windows 开发环境启动脚本

Write-Host "启动开发环境..." -ForegroundColor Green

# 检查虚拟环境
if (-not (Test-Path ".venv\Scripts\activate.ps1")) {
    Write-Host "创建虚拟环境..." -ForegroundColor Yellow
    python -m venv .venv
}

# 激活虚拟环境
.\.venv\Scripts\Activate.ps1

# 安装依赖
Write-Host "检查 Python 依赖..." -ForegroundColor Yellow
pip install -r requirements.txt --quiet

Write-Host "检查 Node 依赖..." -ForegroundColor Yellow
cd frontend-react
if (-not (Test-Path "node_modules")) {
    npm install
}
cd ..

# 启动后端
Write-Host "启动后端服务 (端口 8888)..." -ForegroundColor Green
Start-Process powershell -ArgumentList "-NoExit", "-Command", ".\.venv\Scripts\Activate.ps1; python manage.py runserver 0.0.0.0:8888"

# 启动前端
Write-Host "启动前端服务 (端口 5173)..." -ForegroundColor Green
Start-Process powershell -ArgumentList "-NoExit", "-Command", "cd frontend-react; npm run dev"

Write-Host "开发环境已启动!" -ForegroundColor Green
Write-Host "后端: http://localhost:8888" -ForegroundColor Cyan
Write-Host "前端: http://localhost:5173" -ForegroundColor Cyan
```

### macOS (start-dev.sh)

```bash
#!/bin/bash
# start-dev.sh - macOS 开发环境启动脚本

echo -e "\033[32m启动开发环境...\033[0m"

# 检查虚拟环境
if [ ! -d ".venv" ]; then
    echo -e "\033[33m创建虚拟环境...\033[0m"
    python3 -m venv .venv
fi

# 激活虚拟环境
source .venv/bin/activate

# 安装依赖
echo -e "\033[33m检查 Python 依赖...\033[0m"
pip install -r requirements.txt --quiet

echo -e "\033[33m检查 Node 依赖...\033[0m"
cd frontend-react2
if [ ! -d "node_modules" ]; then
    npm install
fi
cd ..

# 启动后端
echo -e "\033[32m启动后端服务 (端口 8888)...\033[0m"
osascript -e 'tell application "Terminal" to do script "cd \"'$(pwd)'\" && source .venv/bin/activate && python manage.py runserver 0.0.0.0:8888"'

# 启动前端
echo -e "\033[32m启动前端服务 (端口 5173)...\033[0m"
osascript -e 'tell application "Terminal" to do script "cd \"'$(pwd)'/frontend-react2\" && npm run dev"'

echo -e "\033[32m开发环境已启动!\033[0m"
echo -e "\033[36m后端: http://localhost:8888\033[0m"
echo -e "\033[36m前端: http://localhost:5173\033[0m"
```
