# AI 虚拟试衣系统 - 系统说明

> **版本**: v2.0 | **更新日期**: 2026-04-26

---

## 项目简介

基于 Django 5.x + React 的 AI 虚拟试衣系统，支持商家上传服装图片，顾客进行虚拟试穿体验。

### 核心功能

| 功能模块 | 说明 |
|----------|------|
| 商家认证 | 账号密码登录、手机验证码登录 |
| 衣橱管理 | 服装分类管理、批量上传、预设模板 |
| 虚拟试穿 | AI 智能换装、实时预览、历史记录 |
| 试穿配额 | 配额管理、使用统计 |
| 多语言 | 中文、英文、繁体中文 |
| 移动适配 | 响应式设计 |
| 管理后台 | 权限控制、商家管理、数据统计 |
| 操作审计 | 操作日志、系统监控 |

## 数据库表结构

### 核心表

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| `merchant` | 商家表 | uuid, username, phone, role, quota_total, quota_used |
| `clothing` | 服装表 | uuid, merchant_id, category, image_url, image_key |
| `tryon_record` | 试穿记录表 | uuid, merchant_id, avatar_url, result_url, status |
| `tryon_clothing` | 试穿服装关联表 | record_id, clothing_id |
| `sms_log` | 短信验证码表 | phone, code, expired_at |
| `admin_operation_log` | 操作日志表 | admin_id, action, target_type, details |

### 角色字段

`merchant.role` 支持以下值：
- `super_admin`: 超级管理员
- `merchant_admin`: 商家管理员
- `merchant`: 普通商家

详细表结构见 `docker/schema.sql`

## 存储方案

### 图片存储 - 阿里云 OSS

| 图片类型 | 存储路径 | 访问方式 |
|----------|----------|----------|
| 商家头像 | `avatars/{merchant_uuid}/` | OSS URL |
| 服装图片 | `clothing/{merchant_uuid}/` | OSS URL |
| 形象照 | `avatars/{session_id}/` | OSS URL |
| 试穿结果 | `results/{session_id}/` | OSS URL |

### 内容寻址存储 (CAS)

系统支持基于内容哈希的去重存储：
- 上传时计算文件 MD5 哈希
- 相同哈希文件直接复用，不重复存储
- 节省存储空间和上传时间

详见 [content-addressable-storage.md](../docs/content-addressable-storage.md)

## 安全配置

### 数据加密

系统支持请求/响应数据加密（XOR + Base64）：

```bash
# 后端开启
DATA_ENCRYPTION_ENABLED=true

# 前端开启 (src/utils/request.js)
setEncryptionEnabled(true)
```

### RSA 加密登录

管理后台登录使用 RSA 非对称加密：
1. 前端获取公钥：`GET /api/admin/auth/public-key/`
2. 使用 JSEncrypt 加密密码
3. 发送加密后的密码到登录接口
4. 后端使用私钥解密验证

### 安全头 (Nginx)

```nginx
add_header X-Frame-Options "SAMEORIGIN" always;
add_header X-Content-Type-Options "nosniff" always;
add_header X-XSS-Protection "1; mode=block" always;
add_header Strict-Transport-Security "max-age=63072000" always;
```

## AI 引擎

### 支持的引擎

| 引擎 | 代码 | 说明 |
|------|------|------|
| 火山引擎 SeedDream | `seeddance` | 推荐，高质量生成 |
| Mock 引擎 | `mock` | 测试用，返回模拟结果 |

### 引擎配置

```bash
# 默认引擎
AI_ENGINE_DEFAULT=seeddance

# 火山引擎 ARK
ARK_API_KEY=your-api-key
```

### 熔断机制

系统实现了熔断器模式，当 AI 服务异常时自动降级：
- 连续失败 5 次触发熔断
- 熔断后 60 秒内直接返回错误
- 60 秒后尝试半开状态恢复
