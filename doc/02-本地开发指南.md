## 2. 快速开始

### 2.1 克隆项目

```bash
git clone <repository-url>
cd my_project
```

### 2.2 一键启动 (推荐)

```bash
# 启动 Docker 基础服务 (MySQL + Redis)
docker compose -f docker/docker-compose.yml up -d

# 安装后端依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env

# 初始化数据库
docker exec -i tryon-mysql mysql -u root -pRoot@AiTryon2026 tryon_system < docker/schema.sql

# 启动后端
python manage.py runserver 8888

# 启动用户端前端 (新终端)
cd frontend-react && npm install && npm run dev

# 启动管理后台前端 (新终端)
cd frontend-admin && npm install && npm run dev
```

### 2.3 访问地址

| 服务 | 地址 |
|------|------|
| 用户端前端 | http://localhost:5173 |
| 管理后台 | http://localhost:5174 |
| 后端 API | http://localhost:8888/api/v1/ |
| 管理后台 API | http://localhost:8888/api/admin/ |
| Django Admin | http://localhost:8888/admin/ |

## 3. Docker 启动基础服务

### 3.1 启动 MySQL + Redis

```bash
# 启动服务
docker compose -f docker/docker-compose.yml up -d

# 查看状态
docker compose -f docker/docker-compose.yml ps

# 输出示例:
# NAME           STATUS    PORTS
# tryon-mysql    running   0.0.0.0:3308->3306/tcp
# tryon-redis    running   0.0.0.0:6379->6379/tcp
```

### 3.2 服务连接信息

| 服务 | 主机 | 端口 | 用户名 | 密码 |
|------|------|------|--------|------|
| MySQL | localhost | 3308 | root | Root@AiTryon2026 |
| Redis | localhost | 6379 | - | - |

### 3.3 数据库初始化

```bash
# 方式一：使用 SQL 脚本 (推荐)
docker exec -i tryon-mysql mysql -u root -pRoot@AiTryon2026 tryon_system < docker/schema.sql

# 方式二：使用 Django migrate
python manage.py migrate

# 验证表创建
docker exec tryon-mysql mysql -u root -pRoot@AiTryon2026 tryon_system -e "SHOW TABLES;"
```

### 3.4 常用命令

```bash
# 停止服务
docker compose -f docker/docker-compose.yml down

# 重启服务
docker compose -f docker/docker-compose.yml restart

# 查看日志
docker logs tryon-mysql
docker logs tryon-redis

# 进入 MySQL 容器
docker exec -it tryon-mysql mysql -u root -pRoot@AiTryon2026 tryon_system

# 进入 Redis 容器
docker exec -it tryon-redis redis-cli
```

## 4. 后端开发

### 4.1 创建虚拟环境

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux/Mac
python3 -m venv .venv
source .venv/bin/activate
```

### 4.2 安装依赖

```bash
pip install -r requirements.txt
```

### 4.3 配置环境变量

```bash
# 复制示例配置
cp .env.example .env

# 编辑配置
vim .env  # 或使用其他编辑器
```

**开发环境 `.env` 配置：**

```bash
# 环境
DJANGO_ENV=development
DEBUG=True

# 数据库 (Docker)
DB_HOST=localhost
DB_PORT=3308
DB_NAME=tryon_system
DB_USER=root
DB_PASSWORD=Root@AiTryon2026

# Redis (Docker)
REDIS_HOST=localhost
REDIS_PORT=6379

# JWT
JWT_SECRET_KEY=dev-secret-key
JWT_ACCESS_TTL=3600
JWT_REFRESH_TTL=86400

# 阿里云 OSS (开发环境可使用测试 bucket)
OSS_ACCESS_KEY_ID=your-key
OSS_ACCESS_KEY_SECRET=your-secret
OSS_BUCKET_NAME=tryon-dev
OSS_ENDPOINT=oss-cn-shenzhen.aliyuncs.com

# 火山引擎 ARK
ARK_API_KEY=your-api-key
```

### 4.4 启动开发服务器

```bash
# 启动 Django
python manage.py runserver 8888

# 或指定 IP (允许外部访问)
python manage.py runserver 0.0.0.0:8888
```

### 4.5 创建超级管理员

```bash
python manage.py createsuperuser
# 按提示输入用户名、邮箱、密码
```

### 4.6 运行测试

```bash
# 运行所有测试
python manage.py test

# 运行指定应用测试
python manage.py test apps.accounts

# 带覆盖率
pytest --cov=apps
```

### 4.7 代码规范

```bash
# 格式化代码
black apps/ config/
isort apps/ config/

# 检查代码
flake8 apps/ config/
```

### 6.6 RSA 加密登录

管理后台登录使用 RSA 非对称加密：

1. **获取公钥**：调用 `GET /api/admin/auth/public-key/`
2. **加密密码**：使用 JSEncrypt 库加密
3. **发送登录请求**：提交加密后的密码

```typescript
import JSEncrypt from 'jsencrypt';

// 加密密码
const encrypt = new JSEncrypt();
encrypt.setPublicKey(publicKey);
const encryptedPassword = encrypt.encrypt(password);
```

from apps.accounts.models import Merchant

# 创建超级管理员
super_admin = Merchant.objects.create_superuser(
    username='admin',
    phone='13800138000',
    password='admin123',

    username='merchant1',

## 8. 常见问题

### 8.1 MySQL 连接失败

```bash
# 检查容器状态
docker ps | grep mysql

# 检查端口
netstat -an | grep 3308

# 查看日志
docker logs tryon-mysql

# 重启容器
docker restart tryon-mysql
```

### 8.2 Redis 连接失败

```bash
# 检查容器状态
docker ps | grep redis

# 测试连接
docker exec tryon-redis redis-cli ping
# 应返回 PONG
```

### 8.3 端口被占用

```bash
# Windows 查看端口占用
netstat -ano | findstr :8888

# Linux/Mac 查看端口占用
lsof -i :8888

# 结束占用进程
kill -9 <PID>
```

### 8.4 依赖安装失败

```bash
# 清理 pip 缓存
pip cache purge

# 重新安装
pip install -r requirements.txt --no-cache-dir

# 前端依赖问题
rm -rf node_modules package-lock.json
npm install
```

### 8.5 数据库迁移问题

```bash
# 查看迁移状态
python manage.py showmigrations

# 回滚迁移
python manage.py migrate apps.accounts 0001

# 重新生成迁移
python manage.py makemigrations --name your_migration_name
```

### 8.6 OSS 上传失败

```bash
# 检查 OSS 配置
python manage.py shell

>>> from django.conf import settings
>>> print(settings.OSS_ACCESS_KEY_ID)
>>> print(settings.OSS_BUCKET_NAME)

# 测试上传
>>> from apps.common.services.oss_service import oss_service
>>> # 尝试上传测试文件
```

### 8.7 RSA 加密问题

```bash
# 检查密钥文件
ls -la keys/

# 生成新密钥对
make generate-keys

# 测试公钥接口
curl http://localhost:8888/api/admin/auth/public-key/
```
