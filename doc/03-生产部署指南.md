## 2. 服务器初始化

### 2.1 登录服务器

```bash
ssh root@<your-server-ip>
```

### 2.2 一键初始化 (推荐)

```bash
# 下载并执行初始化脚本
curl -fsSL https://your-url/scripts/init-server.sh | bash

# 启用防火墙
ufw enable
```

### 2.3 手动初始化

```bash
# 更新系统
apt update && apt upgrade -y

# 安装基础工具
apt install -y curl wget gnupg git make vim htop ufw

# 设置时区
timedatectl set-timezone Asia/Shanghai

# 安装 Docker
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/debian/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/debian $(. /etc/os-release && echo $VERSION_CODENAME) stable" | tee /etc/apt/sources.list.d/docker.list > /dev/null
apt update
apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

# 启动 Docker
systemctl start docker
systemctl enable docker

# 配置 Docker 镜像加速
mkdir -p /etc/docker
cat > /etc/docker/daemon.json << 'EOF'
{
  "registry-mirrors": [
    "https://registry.cn-hangzhou.aliyuncs.com",
    "https://mirror.ccs.tencentyun.com"
  ],
  "log-driver": "json-file",
  "log-opts": {"max-size": "100m", "max-file": "3"}
}
EOF
systemctl restart docker

# 配置防火墙
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw enable
```

## 3. 项目部署

### 3.1 克隆项目

```bash
mkdir -p /opt/tryon && cd /opt/tryon
git clone <your-repo-url> .
```

### 3.2 配置环境变量

```bash
cp docker/.env.prod.example docker/.env.prod
vim docker/.env.prod
```

**必须修改的配置：**

```bash
# Django
SECRET_KEY=                          # 生成: python3 -c "import secrets; print(secrets.token_urlsafe(50))"
DEBUG=False
ALLOWED_HOSTS=your-domain.com

# 数据库密码
DB_PASSWORD=YourStrongPassword
MYSQL_ROOT_PASSWORD=YourStrongPassword

# 阿里云 OSS
OSS_ACCESS_KEY_ID=
OSS_ACCESS_KEY_SECRET=
OSS_BUCKET_NAME=
OSS_ENDPOINT=oss-cn-shenzhen-internal.aliyuncs.com

# 火山引擎 ARK
ARK_API_KEY=
```

### 3.3 一键部署

```bash
chmod +x scripts/deploy.sh
./scripts/deploy.sh
```

### 3.4 手动部署步骤

```bash
cd /opt/tryon

# 1. 启动基础服务
docker compose -f docker/docker-compose.yml up -d

# 等待 MySQL 就绪
sleep 30

# 2. 初始化数据库
docker exec -i tryon-mysql mysql -u root -pRoot@AiTryon2026 tryon_system < docker/schema.sql

# 3. 构建后端
docker build -t tryon-backend:latest .

# 4. 启动后端
docker compose -f docker/docker-compose.prod.yml up -d backend

# 5. 构建前端
cd frontend-react && npm install && npm run build && cd ..

# 6. 启动 Nginx (见下文)
```

## 4. SSL 证书配置

### 4.1 Let's Encrypt (免费)

```bash
# 安装 certbot
apt install -y certbot

# 申请证书
certbot certonly --standalone \
    -d your-domain.com \
    -d www.your-domain.com \
    --email your-email@example.com \
    --agree-tos --no-eff-email

# 复制证书
mkdir -p /opt/tryon/docker/nginx/ssl
cp /etc/letsencrypt/live/your-domain.com/fullchain.pem /opt/tryon/docker/nginx/ssl/
cp /etc/letsencrypt/live/your-domain.com/privkey.pem /opt/tryon/docker/nginx/ssl/

# 自动续期 (crontab)
echo "0 3 1 * * certbot renew --quiet && cp /etc/letsencrypt/live/your-domain.com/*.pem /opt/tryon/docker/nginx/ssl/ && docker exec tryon-nginx nginx -s reload" | crontab -
```

### 4.2 自签名证书 (测试用)

```bash
mkdir -p /opt/tryon/docker/nginx/ssl
cd /opt/tryon/docker/nginx/ssl
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
    -keyout privkey.pem -out fullchain.pem \
    -subj "/CN=localhost"
```

## 5. Nginx 配置

### 5.1 修改站点配置

```bash
vim /opt/tryon/docker/nginx/conf.d/default.conf

# 将 tryon.example.com 改为你的实际域名
```

### 5.2 启动 Nginx 容器

```bash
docker network create tryon-network 2>/dev/null || true

docker run -d \
    --name tryon-nginx \
    --restart always \
    -p 80:80 -p 443:443 \
    -v /opt/tryon/docker/nginx/nginx.conf:/etc/nginx/nginx.conf:ro \
    -v /opt/tryon/docker/nginx/conf.d:/etc/nginx/conf.d:ro \
    -v /opt/tryon/docker/nginx/ssl:/etc/nginx/ssl:ro \
    -v /opt/tryon/frontend-react/dist:/var/www/html:ro \
    -v /opt/tryon/staticfiles:/var/www/static:ro \
    --network tryon-network \
    nginx:alpine

# 验证配置
docker exec tryon-nginx nginx -t
```

### 5.3 Nginx 配置说明

**`docker/nginx/conf.d/default.conf` 核心配置：**

```nginx
# API 代理
location /api/ {
    proxy_pass http://tryon-backend:8888;
    proxy_read_timeout 120s;  # AI 生成超时
}

# 前端 SPA 路由
location / {
    try_files $uri $uri/ /index.html;
}

# 静态资源缓存
location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}
```

## 6. 日常运维

### 6.1 更新代码

```bash
cd /opt/tryon
git pull origin main

# 更新后端 (不影响前端)
make deploy-backend

# 更新前端 (不影响后端)
make deploy-frontend
```

### 6.2 常用命令

| 命令 | 说明 |
|------|------|
| `make deploy-backend` | 平滑更新后端 |
| `make deploy-frontend` | 平滑更新前端 |
| `make status` | 查看服务状态 |
| `make logs` | 查看后端日志 |
| `make db-backup` | 备份数据库 |
| `make db-migrate` | 执行数据库变更 |

### 6.3 查看日志

```bash
# 后端日志
docker logs -f tryon-backend --tail 100

# Nginx 日志
docker logs -f tryon-nginx

# MySQL 日志
docker logs -f tryon-mysql

# 所有容器状态
docker ps
```

### 6.4 数据库维护

```bash
# 备份
make db-backup

# 执行变更 (编辑 docker/migrations.sql 后)
make db-migrate

# 导出表结构
make db-schema
```

### 6.5 重启服务

```bash
# 重启后端
docker restart tryon-backend

# 重载 Nginx
docker exec tryon-nginx nginx -s reload

# 重启所有服务
docker compose -f docker/docker-compose.yml restart
```

## 7. 故障排查

### 7.1 后端 500 错误

```bash
# 查看日志
docker logs tryon-backend --tail 200

# 进入容器调试
docker exec -it tryon-backend bash
python manage.py check
```

### 7.2 数据库连接失败

```bash
# 检查 MySQL 状态
docker logs tryon-mysql --tail 50

# 检查网络
docker exec tryon-backend ping tryon-mysql

# 检查端口
docker exec tryon-backend nc -zv tryon-mysql 3306
```

### 7.3 前端白屏

```bash
# 检查 Nginx 配置
docker exec tryon-nginx nginx -t

# 检查静态文件
docker exec tryon-nginx ls -la /var/www/html/

# 查看 Nginx 错误日志
docker logs tryon-nginx 2>&1 | grep error
```

### 7.4 SSL 证书问题

```bash
# 检查证书文件
docker exec tryon-nginx ls -la /etc/nginx/ssl/

# 测试 SSL
openssl s_client -connect your-domain.com:443 -servername your-domain.com
```

### 7.5 Docker 问题

```bash
# 查看容器状态
docker ps -a

# 查看资源使用
docker stats

# 清理未使用资源
docker system prune -af

# 查看磁盘空间
df -h
```
